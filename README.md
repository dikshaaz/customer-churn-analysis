# customer-churn-analysis
-This project uses dataset from Kaggle.
-Dataset is cleaned using pandas in jupyter notebook.
-Then imported to sql for extracting insights which tells more about churn and retention opportunity etc.
-Finally the cleaned dataset is the used in power bi to create a dashboard which helps understand cutomer churn in easier way.
-This project can help e-commerce business find why the cutomers are leaving, how can customers be retained and what do they need to improve etc.

## Tools used
-Jupyter lab
-kaggle
-postgresql
-PowerBI
