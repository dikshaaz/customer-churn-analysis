# Customer Churn Analysis

## Project Overview
Customer retention is a critical factor for business growth and profitability. This project focuses on analyzing customer churn behavior by leveraging Python for data cleaning and preprocessing, SQL for extracting business insights, and Power BI for interactive dashboard creation.

The objective is to identify key factors influencing customer churn, uncover trends and patterns, and provide actionable recommendations to improve customer retention strategies.

## Project Workflow
### Data Collection
Imported customer churn dataset.
Examined data structure, features, and target variable.
### Data Cleaning (Python)
Performed:
Handling missing values.
Removing duplicate records.
Data type conversions.
Feature formatting and standardization.
### Exploratory Data Analysis (EDA)
Analyzed:
Churn distribution.
Customer demographics.
Service usage patterns.
Contract types.
Payment methods.
Monthly and total charges.
### SQL-Based Insights
Used SQL queries to extract key business insights such as:
Overall churn rate.
Churn by contract type.
Churn by payment method.
Customer tenure analysis.
Revenue loss from churned customers.
Service-wise churn trends.
High-risk customer segments.
### Dashboard Development (Power BI)
Created an interactive dashboard containing:
Overall Customer Overview
Churn Rate Analysis
Customer Segmentation
Revenue Analysis
Contract Type Insights
Payment Method Analysis
Service Subscription Trends
Retention Opportunity Indicators

## Results

The project successfully identified major drivers of customer churn and provided visual insights through an interactive Power BI dashboard. These findings can help businesses:
Improve customer retention strategies.
Target high-risk customers proactively.
Optimize service offerings.
Reduce revenue loss caused by customer attrition.
